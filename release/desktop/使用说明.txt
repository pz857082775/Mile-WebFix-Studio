WebFix Studio · 桌面版 v1.2.1（Windows x64）
=============================================

【安装版】双击 WebFixStudio-1.2.1-x64-setup.exe（NSIS，推荐）或 WebFixStudio-1.2.1-x64.msi 安装。
【便携版】免安装，直接双击 WebFixStudio-1.2.1-x64-portable.exe 运行。

【依赖】WebView2 Runtime（Win10/11 通常已自带；安装版会自动补装）。
【原理】桌面壳在进程内启动与网页版相同的核心服务，窗口加载同一前端，
因此界面与功能和网页版完全一致；单实例运行，外部链接自动交给系统浏览器。
【窗口】原生无边框窗口：顶部页签栏即标题栏（可拖动、双击最大化），右侧最小化/最大化/关闭；
弹窗为软件风格对话框（标题栏+底部按钮），侧栏可收起，底部状态栏显示服务与规则信息。
【右键菜单】全界面禁用浏览器默认右键菜单；文本框右键为自定义菜单（剪切/复制/粘贴/全选），
选中文字右键可复制；桌面版剪贴板走系统原生通道，复制粘贴稳定不受浏览器权限限制。
【托盘】关闭按钮最小化到系统托盘；托盘右键菜单「打开软件 / 设置软件 / 退出」，左键单击唤起窗口；
真正退出请用托盘右键「退出」。单实例：重复启动自动聚焦已有窗口。

【软件更新】启动时自动检测新版本（可在更新设置关闭）；侧栏「检查更新」或关于页手动检测。
检测到新版本弹窗：可选「立即更新」（下载更新包到本地并打开所在文件夹，手动安装）或「暂不更新」（记住该版本不再打扰）；
默认更新源为 GitHub Releases，也可在「更新设置」填自定义 manifest JSON 渠道；下载完成后按提示关闭本软件再安装。
【更新记录】点击版本号（侧栏 / 状态栏 / 关于页 / 首页）查看历史更新记录；仅展示公开摘要，内部细节保密。
【功能】一键体检 / 全站爬行 / 人工巡检+AI自动操作识别 / 修复工作台(七字段→四件套) /
BUG知识库 / AI设置(零成本默认) / 扩展中心 / 协同编排；多标签页签(单个/批量关闭)，全关回到「米乐大神」落地页。
【真实挖掘】体检/爬行除响应头与HTML启发式外，新增主动无害漏洞探测（反射XSS/SQL报错/开放重定向/路径遍历/CORS反射，
仅发送带标记的GET，不提交表单、不写数据）与链接/资源健康检查（死链、坏图、坏脚本），逐页结果各不相同。
【智能逐页】人工巡检页「智能逐页深度探测」：自动发现全站路由（页内链接+robots+sitemap+前端JS路由），
逐页在内嵌浏览器渲染后做 渲染态UI识别 + DOM体检 + 后端主动探测，按页聚合问题；全站爬行支持点击页面展开该页单独检出的BUG/漏洞。
【登录态复用】先在「人工巡检」内嵌浏览器登录目标站，再到「全站爬行」勾选「复用人工巡检登录态」，
即可扫描登录墙后的页面（体检/路由发现同样复用）；也支持手动填 Cookie / Authorization 兜底。
【演示】内置靶场 /demo（含登录墙 /demo/admin）。

【安全红线】无论添加智能体 / SKILL / AI BOT / MCP，一律禁止执行攻击服务、持久攻击任务、恶意破坏计算机行为与写入恶意脚本；
扩展 cli / stdio 通道仅限已编译的无害检测工具二进制（解释器与攻击/破坏/持久化命令被拒），脚本须走 module 通道且源码自动扫描；
协同编排设总时长上限，拒绝危险参数与恶意脚本写入，全部拒绝行为留审计。
【多平台】Linux / macOS 安装包由 CI（.github/workflows/build.yml）自动构建，
或本机按 docs/BUILD.md 执行 cargo tauri build。

【安全】仅可扫描自有或已获授权的网站；AI 密钥仅存本机、只发往你配置的 API 地址；零成本模式绝不联网大模型。
【配置持久化】AI / 扩展 / 编排 / 审计 / 技能 / 更新设置保存于系统每用户目录（Windows：%APPDATA%\WebFixStudio），
重装 / 升级自动迁移旧配置（旧 ~/.webfix-studio 保留作备份），无需重新配置；「关于」页可查看配置目录。
