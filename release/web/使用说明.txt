WebFix Studio · 网页版 v1.1.0
================================

【运行】双击 webfix-server.exe，然后浏览器打开 http://127.0.0.1:8787
（端口被占用时自动回退 8787–8807，启动窗口会打印实际地址；加参数 --open 可自动开浏览器）

【特点】单文件、免安装：前端界面与 261 条知识库已内嵌，拷贝到任意 Windows 机器即可运行。
Linux / macOS 可用同一源码 cargo run -p webfix-core --bin webfix-server 运行（见 docs/BUILD.md）。

【演示】内置靶场 http://127.0.0.1:8787/demo（含登录墙 /demo/admin），开箱即可体验全部功能。

【功能】一键体检 / 全站爬行 / 人工巡检+AI自动操作识别 / 修复工作台(七字段→四件套) /
BUG知识库 / AI设置(零成本默认) / 扩展中心 / 协同编排；多标签页签(单个/批量关闭)，全关回到「米乐大神」落地页。
【真实挖掘】体检/爬行除响应头与HTML启发式外，新增主动无害漏洞探测（反射XSS/SQL报错/开放重定向/路径遍历/CORS反射，
仅发送带标记的GET，不提交表单、不写数据）与链接/资源健康检查（死链、坏图、坏脚本），逐页结果各不相同。
【智能逐页】人工巡检页「智能逐页深度探测」：自动发现全站路由（页内链接+robots+sitemap+前端JS路由），
逐页渲染后做 渲染态UI识别 + DOM体检 + 后端主动探测，按页聚合问题；全站爬行支持点击页面展开该页单独检出的BUG/漏洞。

【安全】仅可扫描自有或已获授权的网站；AI 密钥仅存本机、只发往你配置的 API 地址；零成本模式绝不联网大模型。
【配置持久化】AI / 扩展 / 编排 / 审计 / 技能保存于系统每用户目录（Windows：%APPDATA%\WebFixStudio），
重装 / 升级自动迁移旧配置（旧 ~/.webfix-studio 保留作备份），无需重新配置；「关于」页可查看配置目录。
